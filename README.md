# ZX_DVD_SCREENSAVER
z80 asm program for the ZX Spectrum 48k to emulate a DVD screensaver. Hello World bounces around the screen and changes colour as it hits the sides.


I asked Claude Sonnet 5.5 if it could make a DVD screensaver for the ZX Spectrum in assembly language. It came out quite nice. Included is the asm file, the python script to make the tape and the .tap file. You will need to assemble the asm into a .bin file using an assembler such as https://github.com/z00m128/sjasmplus

It works very well with FUSE and I expect it will work perfectly well on original hardware too.
